# CodeAlpha Frontend Development — Task 1: Image Gallery

## Project
A responsive image gallery built according to the CodeAlpha Task 1 requirements, with 16 images across 4 categories.

### Included requirements
- HTML + CSS responsive gallery layout
- JavaScript image navigation
- Previous / Next controls
- Full-screen lightbox viewer
- Hover effects
- Smooth transitions and animations
- Responsive design for desktop, tablet and mobile
- Bonus: image category filters

## Files
- `index.html` — page structure and gallery content
- `style.css` — responsive layout, styling, hover effects and animations
- `script.js` — filters, lightbox and keyboard navigation
- `images/` — optional folder for replacing remote images with local images

## How to run in VS Code
1. Extract the ZIP file.
2. Open the extracted `CodeAlpha_Image_Gallery` folder in VS Code.
3. Open `index.html`.
4. For the best development experience, install the **Live Server** extension in VS Code.
5. Right-click `index.html` → **Open with Live Server**.

The project currently uses optimized Unsplash image URLs, so an internet connection is needed for the gallery images.

## JavaScript controls
- Click an image to open the lightbox.
- Click `‹` for previous image.
- Click `›` for next image.
- Press `Left Arrow` / `Right Arrow` on the keyboard.
- Press `Esc` to close the lightbox.
- Use the category buttons to filter the gallery.
